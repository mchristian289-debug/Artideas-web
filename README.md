# Artideas-web
Sitio web de ArtIdeas, fabricante de muebles a medida: cocinas, closets, muebles de TV, centros de entretenimiento y más. Catálogo con filtros y cotización por WhatsApp.


# ArtIdeas | Inspira, Crea y Transforma tu Hogar

Página web de **ArtIdeas**, empresa que fabrica muebles a medida para el hogar.

## Qué ofrece la página
- **Portada** con el nombre de la marca, el eslogan y un fondo de listones de madera.
- **Catálogo con filtros** por línea de producto:
  - Cocinas (muebles superiores, inferiores e integrales)
  - Closets
  - Centros de entretenimiento
  - Muebles de TV (flotantes y de piso)
  - Centros de mesa
  - Mesas de noche
  - Lavamanos de sobreponer
  - Recibidores de sala
- **Cotización por WhatsApp**, desde cada producto o desde el formulario de contacto.
- **Cómo trabajamos**: idea, diseño y medidas, fabricación e instalación.
- **Materiales y acabados**.
- **Redes sociales**: Instagram, Facebook, TikTok, YouTube y WhatsApp.

## Características técnicas
- Un solo archivo `index.html`, sin dependencias ni instalación.
- Diseño adaptable a celular, tableta y computador.
- Modo claro y oscuro automático según el dispositivo.
- HTML, CSS y JavaScript puros.

## Personalización
Para cambiar los datos, edita estas partes del código:
- `WHATSAPP`: número de WhatsApp con indicativo, sin espacios ni signos.
- `DATOS`: lista de productos del catálogo.
- Enlaces de redes sociales y datos de contacto (teléfono, correo y dirección).

## Publicación
Se publica con GitHub Pages desde la rama `main`.
